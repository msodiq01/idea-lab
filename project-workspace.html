IDEA LAB / PROJECT WORKSPACE

Loyiha va jamoa ish maydoni

Loyihangizni yarating, ma’lumotlarini yangilang va jamoaga qo‘shilish jarayonlarini boshqaring. Har bir amal serverdagi ruxsatlar bilan tekshirilishi ko‘zda tutilgan.

Backend hozircha ulanmaganBu sahifa tayyor, lekin Supabase konfiguratsiyasi va idea_app migratsiyalari faollashtirilmaguncha server amallari bajarilmaydi. Kiritilgan ma’lumotlar avtomatik ravishda serverga yuborilmaydi.

Yangi loyiha yaratish

Yangi tashabbus uchun asosiy ma’lumotlarni kiriting. Loyiha standart holatda shaxsiy qoralama sifatida yaratiladi.

Loyiha ma’lumotlarini yangilash

Faqat o‘zingiz boshqarish huquqiga ega bo‘lgan loyiha yangilanadi. Yakuniy ruxsat server RLS qoidalari bilan tekshiriladi.

Jamoaga qo‘shilish so‘rovi

Jamoasiga qo‘shilmoqchi bo‘lgan loyihaning ID raqamini kiriting. So‘rov sizning hisobingiz nomidan yuboriladi.

So‘rov egasi tomonidan ko‘rib chiqiladi. Sizning hisob identifikatoringiz brauzer formasidan olinmaydi — server auth.uid() orqali aniqlaydi.

A’zolik arizalarini boshqarish

Loyiha egasi arizani ko‘rib chiqishi, a’zo esa o‘z a’zoligini tark etishi mumkin.

A’zolik ID loyiha a’zoligi yozuviga tegishli. Amalni bajarishdan oldin server sizning huquqingizni tekshiradi.

Xavfsizlik: ushbu sahifa faqat oldindan belgilangan IDEA LAB buyruqlaridan foydalanadi. Service role kaliti yoki boshqa maxfiy kalitlar brauzerga joylashtirilmaydi. Backend yoqilmagan bo‘lsa, hech qanday serverga yozish amalga oshmaydi.
